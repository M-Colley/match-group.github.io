# MATCH Lab — Website

Source for the **MATCH Lab & Friends** website — *MATCH = Mobility, Accessibility, and Computational HCI* —
led by Dr. Mark Colley at the [UCL Interaction Centre](https://www.ucl.ac.uk/uclic).

🌐 **Live site:** <https://m-colley.github.io/match-group.github.io/>
Built with [Jekyll](https://jekyllrb.com/) and published automatically by GitHub Pages from the `main` branch.

## Adding content (no coding needed)

**See [CONTRIBUTING.md](CONTRIBUTING.md)** for copy-paste templates and step-by-step instructions. Two ways:

- **Open an issue** via the ➕ forms (Issues → *New issue*) — add a publication / team member / news.
- **Edit a file** on GitHub (the ✏️ pencil) and commit to `main`; the site rebuilds in ~1–2 minutes.

Almost everything is data-driven — edit these files in [`_data/`](_data):

| What | File |
|------|------|
| Group lead / contact | `_data/pi.yml` |
| Team members | `_data/team_members.yml` |
| Alumni | `_data/alumni_members.yml` |
| Affiliated PhD researchers | `_data/affiliates.yml` |
| Visiting researchers | `_data/visiting.yml` |
| Publications (teasers in `images/pubpic/`, hover clips in `files/videos/previews/`) | `_data/publist.yml` |
| News | `_data/news.yml` |
| Awards / fellowships | `_data/awards.yml`, `_data/grants.yml` |
| Talks | `_data/invited_talks.yml`, `_data/conference_talks.yml` |
| Page text (home, research, about, team, …) | `_pages/*.md` |
| Site title, tagline, navigation | `_config.yml` |
| Visual design | `css/main.scss` |

Tip: set `selected: true` on a publication to feature it on the home page and at the top of `/publications`.
Put photos in `images/teampic/` (people) or `images/pubpic/` (papers) and reference them by filename.

## How it's published

- GitHub Pages builds and deploys from `main` on every push.
- A **build check** ([`.github/workflows/build-check.yml`](.github/workflows/build-check.yml)) builds the site
  on every push/PR, so a YAML or Liquid error is caught before it can break the live site.
- SEO metadata (OpenGraph / Twitter / JSON-LD) and `sitemap.xml` are generated by `jekyll-seo-tag` and
  `jekyll-sitemap`.

> The site is served as a GitHub **project page** under the `M-Colley` account — hence the
> `…/match-group.github.io/` path and the `baseurl` in `_config.yml`. (The apex `match-group.github.io`
> belongs to a different GitHub organisation, so it can't be used.)

## Building locally

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/match-group.github.io/>.
