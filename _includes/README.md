## About this website

This is the website of the **MATCH Lab &amp; Friends** (*Mobility, Accessibility, and Computational HCI*),
led by Dr. Mark Colley at the [UCL Interaction Centre](https://www.ucl.ac.uk/uclic).

The site is built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages. Its design is adapted —
with substantial customization — from an academic group-website template by
[Ethan Pickering](https://github.com/ethan-pickering/sbryngelson.github.io), itself derived from work by
Spencer H. Bryngelson.

Content (people, publications, news) lives in the `_data/` and `_pages/` directories; the visual design
lives in `css/main.scss`. To suggest a correction, email
[m.colley@ucl.ac.uk](mailto:m.colley@ucl.ac.uk).
